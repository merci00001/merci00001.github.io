# merci00001.github.io

Source of my personal website: **https://merci00001.github.io**

Built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme, deployed to GitHub Pages by the `deploy.yml` workflow.

## Where things live

| What                 | File                                              |
| -------------------- | ------------------------------------------------- |
| Bio / homepage       | `_pages/about.md`                                 |
| Publications         | `_bibliography/papers.bib` (+ `_data/venues.yml`) |
| CV page              | `_data/cv.yml`, PDF in `assets/pdf/`              |
| News on the homepage | `_news/*.md`                                      |
| Social links         | `_data/socials.yml`                               |
| Site-wide settings   | `_config.yml`                                     |

Theme documentation is in [`docs/`](docs/).
